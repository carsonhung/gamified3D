# gamified3D

Game-style 3D and 2.5D scenes for the web, built on three.js. It is the companion to
[gamifiedUI](https://github.com/carsonhung/gamifiedUI): gamifiedUI draws the HUD, panels and
icons in CSS, and gamified3D draws the world underneath them.

The first package will be a low-poly diorama renderer ported from StoryTelling, with terrain,
figures, props and ambient village life. It renders actor positions it is given, so it works
with any game loop (Phaser, plain `requestAnimationFrame` or a framework).

## Status

Early setup. No packages are published yet.
